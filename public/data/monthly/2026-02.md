# 2026年2月媒体平台更新月报

2026年2月，主流广告平台迎来多项重要更新。Meta正式发布Graph API v25.0，带来全新的Page Viewer Metric指标；TikTok Smart+ API扩展预算控制选项，为广告主提供更精细的投放管理能力；Pinterest推出购物模板功能，简化产品目录广告的创建流程；Amazon Ads与Spotify达成程序化合作，并面向Sponsored Ads广告主开放AMC高级分析能力。Mintegral则针对CPE出价和AppGrowth学习阶段提供优化指南。本月更新以API增强和程序化能力升级为主，建议广告投放团队重点关注Meta API迁移和Amazon AMC功能拓展。

---

## 社交/短视频

### TikTok

TikTok本月通过Smart+ API端点的升级，显著增强了非CBO广告系列的预算管理能力。广告主现在可以在调用 `/smart_plus/campaign/create/`、`/smart_plus/campaign/update/` 以及 `/smart_plus/campaign/get/` 端点时使用全新的预算模式枚举值。其中 `BUDGET_MODE_DAY` 支持设置每日预算上限，而 `BUDGET_MODE_TOTAL` 则允许定义广告系列的总预算限额，这些预算设置将统一应用于该广告系列下的所有广告组。这一改进对于需要精确控制广告支出节奏的投放团队尤为实用，尤其是在大促期间或需要阶段性测试不同投放策略时，广告主可以更灵活地在日预算和总预算之间切换，确保资金使用效率最大化。

### Meta

Meta于2月中旬正式发布了Graph API v25.0和Marketing API v25.0，这是当前最新的稳定版本，将获得Meta的长期支持。值得注意的是，该版本计划在2026年6月底前引入全新的Page Viewer Metric（页面浏览量指标），用于替代现行的reach（覆盖）指标。官方建议开发团队尽快查阅[Graph API v25.0 发布公告](https://developers.facebook.com/blog/post/2026/02/18/introducing-graph-api-v25-and-marketing-api-v25/)中的详细变更说明，同时查看[Graph API v25.0 正式发布页面](https://developers.facebook.com/docs/graph-api/changelog)获取完整的升级指南。由于v24.0将于2026年10月6日到期，v23.0将于2026年6月9日到期，依赖旧版API的广告主应尽早启动迁移规划，以免影响广告投放的正常运作。

### LinkedIn

LinkedIn营销博客本月发布了一篇关于B2B营销领导者如何利用视频内容建立公信力的深度分析。文章引用了CES 2026的行业洞察，展示了企业高管如何通过真实、专业的视频内容有效扩大个人品牌影响力。该研究对广告投放团队的启示在于：高管层出镜的原生视频内容能够显著提升品牌在B2B受众群体中的信任度。建议营销团队在制定LinkedIn广告策略时，可考虑融入真实的高管人设内容，通过更具人格化的表达方式触达决策者群体，实现品牌认知与信任建设的双重目标。

## 视频

### Amazon

Amazon Ads本月在视频广告领域继续保持高频更新节奏，推出了多个具有参考价值的案例研究和产品指南。

在创意生产效率方面，[传统医药品牌Traditional Medicinals借助AI技术在三周内完成流媒体电视广告的制作与上线](https://advertising.amazon.com/en-us/library/case-studies/traditional-medicinals-streaming-tv/?ref_=a20m_us_libr)，展示了AI工具在缩短广告创意生产周期方面的巨大潜力。这一案例对于追求快速响应市场变化的投放团队具有借鉴意义，AI辅助的视频创意生产有望成为未来广告运营的标准配置。

在虚拟试穿技术应用上，[美宝莲的虚拟试唇体验功能带动转化率增长63%](https://advertising.amazon.com/en-us/library/case-studies/maybelline-lipstick-finder-virtual-try-on/?ref_=a20m_us_libr)，印证了沉浸式产品体验对电商转化率的显著提升效果。对于美妆、时尚、家居等依赖视觉体验的品类，广告主应积极探索在产品详情页和广告素材中嵌入AR试用功能。

此外，[达美乐加拿大通过娱乐化营销策略实现品牌增长](https://advertising.amazon.com/en-us/library/case-studies/dairy-queen-canada/?ref_=a20m_us_libr)同样值得关注。该案例表明，在广告素材中融入娱乐元素、与用户建立情感连接，能够有效突破传统的产品功能诉求，在竞争激烈的快消品市场中实现差异化突围。

## 亚洲区域

### Pinterest

Pinterest本月面向广告主推出了购物模板功能，这一更新将大幅简化产品目录广告的创建流程。广告投放团队可以通过购物模板快速将产品目录数据转化为格式规范、视觉统一的广告素材，无需逐一手动制作单品图片和文案。该功能特别适合拥有大量SKU的电商广告主，能够显著提升购物广告的上新效率和规模化管理能力。建议团队尽快熟悉这一功能的工作流程，在素材制作环节引入模板化生产模式。

与此同时，Pinterest发布的2026年育儿趋势报告揭示了一个值得关注的新兴用户行为模式：当代父母正在积极培养孩子在数字时代的“屏幕智慧”，更加注重屏幕时间管理与现实世界体验的平衡。报告显示，儿童正在成为推动家庭消费决策的重要因素，这对广告投放团队的启示是：家庭、亲子教育品类的品牌在规划Pinterest广告时，应重点关注家长对“屏幕智慧”类产品的需求，如教育应用、户外活动装备、创意学习工具等品类的搜索量和互动率可能呈现上升趋势。

### LINE

LINE官方本月发布了DE&I（多元化与包容性）视角的替换用语指南，专门针对广告主和内容运营者提供文案表达优化建议。该指南强调，同一条信息采用不同的表达方式可能产生截然不同的传达效果，尤其是在涉及年龄、性别、文化背景等敏感议题时。指南提供了大量具体案例，例如将「老年人」替换为「65岁以上人群」，将带有刻板印象的职业描述改为更中性的表达方式。广告投放团队在创作面向日本市场的营销内容时，可将该指南作为文案审核的参考标准，一方面确保内容符合当地社会文化规范，另一方面通过使用包容性语言提升品牌形象和社会责任感知。

## 程序化/DSP

### Amazon

Amazon Ads本月在程序化广告领域推出了几项重要的能力扩展和产品合作。

首先，[Amazon Ads与Spotify Ads宣布达成程序化合作](https://advertising.amazon.com/library/news/spotify-amazon-dsp-programmatic-integration?ref_=a20m_us_lbr_psn_z2_unid_nws_sptfyads)，通过Amazon DSP即可触达Spotify的优质音频用户资源。这一整合意味着广告主可以在统一的DSP平台上同时管理电商、视频、展示等多渠道的音频广告投放，简化跨平台投放的运营复杂度。对于追求全渠道覆盖的品效合一营销策略，该合作为音频广告投放提供了便捷的接入通道。

其次，[AMC（Amazon Marketing Cloud）现已面向Sponsored Ads广告主开放](https://advertising.amazon.com/library/news/amc-for-sponsored-ads?ref_=a20m_us_lbr_psn_z2_unid_nws_amcsa)，这一消息对Sponsored Products和Sponsored Brands的广告主而言意义重大。AMC提供了强大的隐私安全云端分析能力，支持广告主跨触点分析用户行为路径、评估广告协同效应、构建自定义受众模型。这意味着投放团队可以更深入地理解广告投入与用户转化的真实关系，为预算分配和策略优化提供数据支撑。建议Sponsored Ads广告主积极申请AMC访问权限，探索自定义分析场景。

在广告投放技巧方面，[Amazon Ads博客总结了五条专家建议帮助广告主规避Sponsored Ads的常见错误](https://advertising.amazon.com/library/expert-advice/common-sponsored-ads-mistakes-and-solutions?ref_=a20m_us_lbr_psn_z2_unid_exp_samistk)，涵盖关键词策略、出价优化、预算分配等核心议题。同时，关于[验证供应源（Verified Supply）如何重塑程序化广告生态](https://advertising.amazon.com/en-us/library/expert-advice/verified-supply-programmatic-advertising/?ref_=a20m_us_libr)的分析文章指出，供应源验证机制正在成为程序化广告质量保障的重要一环，广告主在选择投放位置时应关注库存质量认证。

在案例研究方面，[Cocolab通过Amazon Ads实现新品牌客户销售增长80%](https://advertising.amazon.com/library/case-studies/cocolab?ref_=a20m_us_lbr_psn_z2_unid_cs_colb)的经验表明，结合品牌旗舰店与效果广告的协同投放策略能够有效拉动新客获取；而[Serta的案例](https://advertising.amazon.com/en-us/library/case-studies/serta-ocm/?ref_=a20m_us_libr)则揭示了一个重要洞察：62%的展示广告影响发生在亚马逊平台之外，印证了全渠道归因分析对于理解真实营销效果的必要性。

## 国内厂商海外渠道

### Mintegral

Mintegral本月持续深耕移动广告优化的知识分享，针对投放团队关心的两大核心议题提供了实用指南。

在出价策略优化方面，平台详细解析了[目标CPE（每次参与成本）出价策略的运作机制与优化方法](https://www.mintegral.com/en/blog/faq-target-cpe-bidding)。CPE出价模式适合以用户参与度为优化目标的广告活动，如社交类、休闲游戏类应用。指南涵盖了如何设定合理的CPE目标值、如何通过素材优化提升参与率、以及如何根据活动数据迭代出价策略，对于追求高效获客和优化投放ROI的团队具有直接指导价值。

在规模化投放方面，[Mintegral发布的AppGrowth学习阶段突破指南](https://www.mintegral.com/en/blog/faq-overcoming-the-learning-phase)为广告主提供了四条实战技巧，帮助缩短冷启动周期、加速学习期优化进程、降低初期投放成本。学习阶段一直是程序化投放中的效率瓶颈，尤其对于追求快速起量且期望稳定ROAS的广告主而言，如何在有限的测试预算内快速完成模型校准至关重要。该指南建议投放团队关注素材多样性、出价策略一致性、受众定向的精准度等维度，系统性地提升广告系列的学习效率。

## 总结与建议

2026年2月的平台更新呈现出几个显著趋势：API层面，各主流平台持续完善开发接口的能力边界，为自动化投放和精细化管理提供底层支撑；产品层面，购物广告模板、AMC开放等更新降低了规模化管理的技术门槛；合作层面，Amazon与Spotify的程序化整合预示着跨平台流量聚合将成为DSP发展的新方向。

建议广告投放团队本月重点关注以下行动项：一是评估Meta Graph API v25.0的迁移时间表，提前规划旧版本废弃前的系统适配工作；二是评估Amazon AMC功能对Sponsored Ads分析能力的提升，优先探索高价值自定义受众模型的构建方法；三是梳理现有的产品目录广告生产流程，研究引入Pinterest购物模板的可行性；四是回顾Mintegral的学习阶段优化指南，针对在投活动进行系统性诊断与调优。
